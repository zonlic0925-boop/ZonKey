# ZonScale 背景外观/主题系统调研报告

> 2026-09-01 · 用户需求：「添加不同的背景外观供用户选择」——本轮**只调研不动代码**，结论供下轮决策。

## 一、现状盘点

- 色彩真源在 `frontend/tailwind.config.js`：`mem-*` 色板（cream 底 `#FFF9F0` + ink `#1A1A2E` + 8 强调色）+ 3 档 Memphis 硬阴影。
- 全站组件**硬编码 mem 类名**（`bg-mem-cream`、`border-mem-ink` 等，约 60+ 处文件）。没有 CSS 变量层。
- 装饰层 `MemphisDecor.tsx` 是绝对定位的几何图形（固定色值），深色底下会出现对比度问题。
- 壳层 `desktop_app.py` 的 `background_color="#FFF9F0"` 与页面底色耦合（启动闪屏颜色）。

## 二、用户真正要什么（第一性原理）

「不同的背景外观」大概率不是换色板这么窄——用户想要**整体氛围可选**（明亮/柔和/深色），并且**持久记忆**。约束是：

1. Memphis 风格的识别度来自「奶油底 + 粗黑描边 + 硬阴影」三件套；描边/阴影颜色若跟着变，风格就散了。**客观约束：ink（描边色）应保持稳定，变的是底色、卡底、强调色明度。**
2. 脱敏工作台是生产力工具：图纸/文档预览区的色彩还原度不能被主题干扰——**画布预览区应始终中性底**（不透明度/白底），主题只影响工作台 chrome。
3. 发布版离线工具，禁止引入 CDN 主题或在线壁纸——所有外观资产本地化。

## 三、三个方案（按改动成本排序）

### 方案 A：CSS 变量主题层（推荐）

Tailwind 色板改挂 CSS 变量：

```js
// tailwind.config.js
colors: { mem: {
  cream: 'var(--mem-cream)', ink: 'var(--mem-ink)', coral: 'var(--mem-coral)', ...
}}
```

`:root` 定义默认值；`data-theme="dark"` 等属性选择器覆盖变量。换主题 = 根元素一个 `data-theme` 属性，localStorage 记忆。

- **成本**：一次性改 tailwind.config + index.css 定义 3-5 套变量 + 壳层启动闪屏同步读主题。组件类名**零改动**（这是关键优势——60+ 文件不用碰）。
- **预设建议 4 套**：`cream`（现状默认）/ `paper`（更素的白纸底，弱化孟菲斯装饰）/ `dark`（深底 + 描边改浅灰白 + 硬阴影改黑）/ `slate`（冷灰护眼）。
- **风险**：硬阴影 `shadow-memphis` 色值写死在 config 里，需一并变量化；MemphisDecor 几何件颜色要跟变量走；截图/PDF 导出不受影响（导出走后端/画布，与 DOM 主题无关）。

### 方案 B：仅背景纹理/壁纸层（最轻）

不动色板，只提供可换的背景层：纯色 / 网格纸 / 点阵 / 米黄纹理，铺在 `MemphisDecor` 底下，内容卡片仍是白底不透明所以可读性天然安全。

- **成本**：半天级。一个 `BackgroundPicker` + localStorage + 4-5 个 CSS 背景（离线，可用 SVG data-URI 网格）。
- **局限**：满足「背景外观」，满足不了「深色模式」期待。如果用户实际想要的是深色主题，B 会返工。

### 方案 C：完整多主题品牌系统（过重）

多套完整色板（如海洋/森林/日落主题，各自 10 色 + 3 档阴影）+ 主题预览 UI。

- **不建议**：Memphis 识别度会被稀释成「换皮工具」；维护成本高；对脱敏核心价值无增益（TOC：当前瓶颈是核心脱敏体验与发布收尾，不是皮肤数量）。

## 四、决策建议

**A 为主、B 为其子集**：先落 CSS 变量层 + 4 套预设（含深色），背景纹理作为每套主题内的二级选项（可选做）。入口放首页导航页或 Header 齿轮。壳层 `background_color` 与主题联动（读 localStorage 的同步脚本注入 `webview.create_window` 前）。

**下轮实施清单（预估 1-1.5 天）**：
1. tailwind.config 色板/阴影变量化 + `index.css` 4 套 `data-theme` 变量块；
2. `ThemeProvider`（React context + localStorage + `data-theme` 属性写入 `<html>`）；
3. 首页/设置区外观选择卡（缩略预览，点击即换即存）；
4. MemphisDecor、滚动条、`desktop_app.py` 闪屏色、` zs-win-ctrl` 跟随变量；
5. 回归：对比度抽检（ink on 各底色 ≥ 4.5:1）、图纸预览区中性底验证、手机端 Playwright 溢出检查。

**开放问题（需用户拍板）**：要不要深色模式？（脱敏工具用户多为办公场景，深色需求存疑但常有期待）；背景纹理要不要？若只要「换背景不要换色」，直接做 B 最省。
