## 发布建议

1. **发布时间**：工作日晚 21:00–22:30 或周末上午，打开率最高。
2. **选图**：朋友圈九宫格会裁成方形预览，第 1 张（封面）决定点击欲，文案里的二维码在评论区再发一遍链接补刀。
3. **评论区补流**：发出后自己在评论区置顶一条「网页版直接用：https://zonkey.pages.dev（点不开就复制到浏览器）」，比正文里的域名更可信。
4. **间隔**：A 文案首发 → 3~5 天后换 C 文案重发（换 3/4/7 三张图做新组合），避免重复感。
5. **桌面版下载**：GitHub 搜 ZonKey（zonlic0925-boop/ZonKey），Release 里有安装包和便携版；网页版下载弹窗里已内置国内加速线路。
